## Capabilities

- Plan Paddle Billing architecture for an existing application
- Design catalog, pricing, and localized pricing pages
- Implement checkout and secure webhook processing
- Synchronize subscriptions and gate application entitlements
- Test integrations in Paddle sandbox
- Debug integrations and audit production readiness
- Connect to Paddle live through Paddle's official MCP and OAuth
